                        HOW IT WORKS
                    


                    

                        From image to recognition.
                    


                    

                



                


                    

                    


                        
                            01
                        

                        

                            
                        


                        

                            Capture
                        


                        

                            Capture a face using the camera or
                            upload an image.
                        


                    



                    

                    


                        
                            02
                        

                        

                            
                        


                        

                            Analyze
                        


                        

                            InsightFace detects the face and
                            generates a 512-dimensional embedding.
                        


                    



                    

                    


                        
                            03
                        

                        

                            
                        


                        

                            Recognize
                        


                        

                            The embedding is compared against
                            enrolled users using PostgreSQL and
                            pgvector.
